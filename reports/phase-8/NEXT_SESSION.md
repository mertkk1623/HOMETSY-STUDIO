## 1. The one outstanding evidence item

### Run a real screen-reader pass — NOT VERIFIED in Phase 8

This is the only item that Phase 8 could not evidence. Automated axe-core scans
report **zero violations on nine screens**, but no assistive technology was
driven, so the reports say `NOT VERIFIED` rather than claiming accessibility.

**What to do**

1. Start the app:
   ```
   .venv\Scripts\python.exe -m streamlit run app.py --server.port 8512 --server.headless true
   ```
2. Install NVDA (free, Windows) and start it with `Ctrl+Alt+N`.
3. Walk the nine screens in this order with the keyboard only, listening rather
   than looking:
   - landing → room setup → design preferences → project review
   - design brief (before and after **Analyse the brief**)
   - design concepts (before generation, generated, selected)
   - design plan (before the advisor, after **Recommend furniture and build the plan**)
   - design evaluation (before and after **Evaluate the design**)
   - budget analysis → final report
4. Record, per screen:
   - Is the page title announced first, and is it the right title?
   - Is the stage ("Stage 3 of 5 · Concepts") read in the right order, and does
     it make sense spoken aloud?
   - Does the skip link work and is it announced?
   - **The plan drawing:** the frame is `tabindex="0" role="group"` with the
     label *"Room plan drawing. Scroll sideways to see the whole plan."* — confirm
     it is announced, focusable, and that its inner text is not read as noise.
   - **The cost chart:** the `alt` is generated by
     `ui/pages_budget.distribution_alt_text()`. Confirm it is read and is
     comprehensible when spoken, not just present.
   - Are form errors and status changes announced when they appear?
5. Write the result to `reports/phase-9/ACCESSIBILITY_REPORT.md`.

**Then, and only then**, the accessibility verdict can move from
*PASS (automated) / NOT VERIFIED (screen reader)* to a single **PASS**. If the
pass finds wording or order problems, fix them — the structure is already sound,
so the likely findings are copy and ordering, not markup.

**Do not** claim WCAG conformance on the strength of this pass either. A single
screen-reader run on one browser is strong evidence, not a certification.

## 2. Optional, low priority

### The plan frame's empty margin between 640 and 1024 px

The drawing keeps a 640 px floor and scrolls inside its frame. Below 1024 px the
frame is sometimes wider than the drawing, so there is visible empty space to the
right of the plan. This is a deliberate trade — legibility over density — and it
causes no page overflow at any width. It is cosmetic.

If it is addressed, note the constraint: the label font is 9 user units, so the
drawing cannot be scaled below 1.0 without dropping under ~9 px. The fix is a
max-width on the svg plus centring, not a smaller floor.

### The asset redistribution decision

The reference images are **original AI-generated reference sheets created for
this project**; no third-party stock is used. `assets/source_pack/asset_manifest.json`
records `"Review applicable platform terms before external redistribution."`

Before the repository is published, decide whether those terms permit
redistribution. The two excluded source assets (`modern.jpg`, `minimalist.jpg`)
must stay excluded, and the Japandi / Warm Minimalism replacements that
`data/asset_replacements.json` records must remain the ones the app uses.

## 5. Things that will bite you

Learned the hard way during Phase 8, so they are written down:

- **`-X utf8` is required** for any Python invocation that prints Turkish text.
  Without it the console raises on `ı`, `ş`, `ğ`.
- **Never round-trip a UTF-8 source file through PowerShell `Get-Content -Raw` /
  `Set-Content`.** It silently re-encodes to cp1252 and adds a BOM. Use the edit
  tools, or a Python script with `encoding="utf-8", newline=""`.
- **The browser viewport resets between `execute` calls.** Call
  `page.setViewportSize()` *inside the same call* as the screenshot, or you will
  capture 878 px and wonder why.
- **Editing a source file while Streamlit is running** poisons the live session:
  `TypeError: The session contains a value that is not a WorkflowState under
  'hm_workflow_state'`. It is a hot-reload artefact, not a product bug. Restart
  the Streamlit process and use a fresh browser session.
- **The advisor call is occasionally truncated** by the provider. The app reports
  it honestly and stores nothing; retry. Do **not** raise `max_tokens` — that is
  an AI-contract change requiring owner approval (`AGENTS.md` §15).
- **`files.write` in the browser tool is limited to the temp directory.** Capture
  to `C:\Users\[LOCAL_USER]\AppData\Local\Temp\opencode\shots\`, then copy into
  `docs/screenshots/`.
